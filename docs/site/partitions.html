Select a slice deliberately

Plan one date. Then run that date.

A partitioned asset represents independent slices of one task—often dates, regions, or tenants. The script owns what keys mean; the CLI lets you select them explicitly.

Review before rerunning

# First inspect one partition without executing asset bodies.
kazeflow plan daily.py --target publish_daily --partition-key 2026-08-08

# Then execute exactly that reviewed selection.
kazeflow run daily.py --target publish_daily --partition-key 2026-08-08 --yes

Select more than one partition

--partition-key is repeatable. It passes strings to the script's partition definition; kazeflow does not guess types or manufacture a current date.

kazeflow plan daily.py --partition-key 2026-08-08 --partition-key 2026-08-09

Know what selection means

InputMeaning
Omit --partition-keyNo explicit CLI selection; the partition definition determines the work.
Pass one or more keysRequest those exact string values as the selection.
Python API empty selectionRepresents no partition work when the flow supports it.
Falsey Python keys0, "", and False remain present values, not omission.
Plan is still a loading operation.

Use partition review only with Python source you trust. The CLI loads the entry before it can determine valid partitions; plan does not sandbox that load.
