What kazeflow is for

Start with a script. When it becomes several dependent steps, keep the functions plain Python and add just enough structure to see the work order, choose the target, and inspect the outcome. kazeflow is intentionally not a scheduler, remote worker system, database-backed platform, or sandbox.

Trust boundary.

A CLI command loads your Python entry, and importing a module can execute its top-level code. plan does not invoke asset bodies after the entry is loaded; it does not make an untrusted script safe. Read and trust the source before loading it.
