Review from the terminal

Inspect what will run.

The CLI is a thin review layer over a normal Python script. It offers human-readable text and a stable JSON boundary for automation.

CommandUse it for
kazeflow assets ENTRYList assets discovered while loading a trusted script.
kazeflow plan ENTRYReview targets, dependency order, configuration, and graph.
kazeflow run ENTRYReview a preflight, then explicitly execute the selected work.
kazeflow runs …List, show, or compare explicitly stored runs.

Start with a plan

kazeflow plan daily.py
kazeflow plan daily.py --target publish
kazeflow plan daily.py --format json

Pass a bare .py file when it exports flow, or use an explicit entry such as package.module:flow. If a bare script has no flow, kazeflow derives its terminal discovered assets.

Choose the graph that fits the review

# Read the concise graph in a terminal.
kazeflow plan daily.py

# Paste into GitHub Markdown or another Mermaid renderer.
kazeflow plan daily.py --format mermaid

# Use an external Graphviz renderer when you want a laid-out image.
kazeflow plan daily.py --format dot > flow.dot

kazeflow deliberately does not install or invoke Mermaid or Graphviz. JSON is the right format for programs; text, Mermaid, and DOT are review projections.

Run and result output

kazeflow run daily.py
kazeflow run daily.py --yes --verbose
kazeflow run daily.py --yes --format json

Text lists task status and duration. --verbose adds safe attempt-level detail. JSON writes one portable result document to standard output; progress and diagnostics remain on standard error.

Loading is part of trust.

Entry resolution imports Python code and can have top-level side effects. Do not point the CLI at untrusted code. plan guarantees that asset bodies are not invoked after entry loading, not that importing is harmless.
