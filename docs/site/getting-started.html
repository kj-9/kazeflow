First reviewed run

From one script to a deliberate run.

The normal path is: write a flow, inspect it, decide to run it, then review the result.

1

Install

The core has no required runtime dependency.

pip install kazeflow
pip install "kazeflow[tui]"  # optional Rich progress display
2

Declare a flow in a Python file

Assets are ordinary functions. Export a module-level flow to name the default target.

# daily.py
from kazeflow import Flow, asset

@asset
def fetch() -> str:
    return "report input"

@asset
def publish(fetch: str) -> None:
    print(fetch)

flow = Flow(["publish"])
3

Inspect before execution

This shows the selected target, dependency order, and graph without calling either asset body.

$ kazeflow plan daily.py
Plan: publish
2 assets · no partition selection · default concurrency
Graph:
  fetch
  fetch --> publish *

The * marks the selected target. This is a representative text review: no asset body has run.

4

Run only after an explicit decision

In a terminal, review the preflight and answer y. In CI or a pipe, pass --yes.

$ kazeflow run daily.py
Planned run:
Plan: publish
2 assets · no partition selection · default concurrency
Graph:
  fetch
  fetch --> publish *
Proceed? [y/N] y
Run result:
- run_id: <run-id>
- status: success
- duration: <duration>
Tasks:
- ✓ fetch (success; <duration>)
- ✓ publish (success; <duration>)

run_id and durations vary each time. Text is for review; use --format json when another program needs a stable record.

5

Read or retain the result

Text output summarizes every task. Add --store to retain a portable result record, then inspect it later.

kazeflow run daily.py --yes --store .kazeflow/runs.sqlite3
kazeflow runs list
kazeflow runs show RUN_ID
Before you load a script:

Python module loading can execute top-level code. Plan skips asset bodies only after that loading step. kazeflow helps you review a trusted flow; it is not a sandbox.
